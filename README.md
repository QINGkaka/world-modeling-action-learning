# What Does World Modeling Actually Improve in Robot Action Learning?

**Hanwen Cui<sup>*</sup>, Yuanyuan Li<sup>*</sup>, Qing Guo, Zhida Zhang, Chao Chen<sup>†</sup>, Xi Chen, Jie Cao<sup>‡</sup>**

<sup>*</sup> Equal contribution &nbsp;&nbsp; <sup>†</sup> Project lead &nbsp;&nbsp; <sup>‡</sup> Corresponding author

This work presents a controlled study of world-model supervision in robot action learning. Across FastWAM, OpenWAM, and pi0.5, we examine when predictive supervision improves policy learning, how it changes behavior, and whether its benefits persist under task and environment shifts.
